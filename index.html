Sync between devices

Keeps this profile in step across your phone and PC by saving to a private Gist on your GitHub account. Set it up once on each device with the same token. Each person should use their own GitHub account.

  1. Open GitHub → New token (the “gist” box is already ticked; tick nothing else).
  2. Set Expiration to “No expiration” (or a date you’ll remember), click Generate, and copy the token.
  3. Paste it below and click Connect. Do the same on your other device.

Backup

Data is stored in this browser. Export a backup now and then, especially if you don’t use sync.
