Sync between devices

Keeps your phone and PC in step automatically by saving to a private Gist on your GitHub account. Set it up once on each device with the same token.

  1. Open GitHub → New token (the “gist” box is already ticked; tick nothing else).
  2. Set Expiration to “No expiration” (or a date you’ll remember), click Generate, and copy the token.
  3. Paste it below and click Connect. Do the same on your other device.

Backup

Your data is stored only in this browser. Clearing site data or switching browsers will lose it, so export a backup regularly.
